# fieldops-agent-lab

A small app we build with AI agents, one layer at a time, in the GH-600 course.

- Run it: npm ci, then npm run dev, then open http://localhost:5173
- Check it: bash scripts/verify.sh
- Product spec: docs/SPEC.md
- Tasks: the Issues tab (one per layer)
- Behind? Switch to the branch layer-N-done for the layer you are on.
