# Show the work orders in the web app

<!-- Layer 3 (run before and after AGENTS.md) -->

## Goal
People can see their work orders in the web app, with status and priority filters.

## Success criteria
- A table with id, title, asset, site, priority, risk, status.
- Status and priority filters.
- Switching the user in the dropdown shows that user's work orders.

## Scope
In: web/ only. Out: api/, mcp/.

## Risk
Low.
